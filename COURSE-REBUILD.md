# The complete guided course

The active goal is to rebuild all 30 lessons as clear, substantial learning experiences with a real exercise and project after every lesson. The approved Amina sample supplies the simple opening interaction. Clicking a demonstration is only the beginning of a full lesson.

## Teaching and product requirements

- Every lesson pairs at least two related concepts with a concrete problem at Amina's growing shop.
- Introduce new words in plain English and connect each new idea to something already learned.
- Start with one obvious action. Present explanations in short sections and exercises one step at a time.
- Each lesson contains a worked example, line-by-line explanation, meaningful code exercise, helpful hints, reference solution, normal and boundary/failure checks, an independent extension, and reflection prompts.
- Exercises run the learner's actual code. HTML/CSS/DOM/React exercises render real interfaces. Python and SQLite exercises run actual Python. Prepared AI responses are explicitly labelled; fixture results never stand in for evidence about a real model.
- Every project has a brief, milestones, acceptance criteria, test cases, runnable starter files, commands, and a downloadable kit. Later projects join the frontend, backend, data, and AI work into one product.
- Track completed exercise steps, current drafts, project evidence, and reflections in browser storage and backups. Preserve older course records without marking new lessons as completed.
- The new course becomes the default opening and learning path. Keep the older workshops available as a reference library.
- Finish with an independent capstone and an evidence-based readiness review. Course completion records practice; job readiness requires demonstrating skills independently. Avoid automatic employment or mastery promises.

## The 30 lessons

1. Variables and input/output: count incoming and answered messages.
2. Conditions and validation: reject bad input and route urgent requests.
3. Arrays, objects, and loops: manage a real inbox.
4. Functions and clear boundaries: calculate reliable order quotes.
5. JSON, saved state, and errors: recover a saved shopping list.
6. Tests and debugging: find and fix an incorrect total.
7. Git, review, and reproducible setup: deliver a reviewed change.
8. HTML and accessible forms: collect a customer's message.
9. CSS and responsive design: make the inbox usable on a phone.
10. DOM events and state: build a working message interface.
11. Async requests and HTTP errors: load orders reliably.
12. React, components, and TypeScript: build a typed interactive inbox.
13. Python and translating concepts: move order rules to the backend.
14. SQL, relationships, and transactions: persist orders in SQLite.
15. API contracts, validation, and FastAPI: expose order operations.
16. Identity, permissions, and safe input: separate customers' data.
17. Frontend/backend integration and error handling: join the application.
18. Testing services and deployment: release a working full-stack product.
19. Language models, tokens, and uncertainty: select and budget an AI task.
20. Prompts, schemas, and model adapters: classify customer messages.
21. Tools, validation, and human approval: give AI limited capabilities.
22. Embeddings, retrieval, and ranking: find relevant shop policies.
23. RAG, citations, and abstention: answer using evidence.
24. Evaluation, datasets, and regression: measure AI quality.
25. Agent workflows, stopping, and budgets: build a bounded assistant.
26. Logs, privacy, and recovery: investigate and fix an incident.
27. Discovery, scope, and outcomes: turn customer needs into a brief.
28. Capstone architecture and implementation: assemble a customer-ready assistant.
29. Security, deployment, and rollback: harden and release the capstone.
30. Demonstration, handoff, and readiness: explain and defend the working product.

## Completion audit

Completion requires inspecting all 30 content records and downloadable kits; executing every reference solution and its checks; exercising every lesson route and progression flow; verifying HTML, React, Python, SQL, async, and backend behavior with appropriate runtime tests; testing progress restore, backup compatibility, keyboard/mobile layouts, isolation, and error recovery; building the real full-stack/AI capstone and running its integration tests; reviewing the final readiness rubric; publishing and verifying the new default course; and submitting the source change for review.

Optional further practice should address gaps found in the readiness review rather than introduce an arbitrary completion deadline. Microsoft AI for Beginners is a learning-design reference: https://github.com/microsoft/AI-For-Beginners. New lesson prose and exercises are authored for this course.
