# 📘 Day 28 — Capstone, Part 1: Build

**Concept:** Everything composed under a deadline: RAG + API + guardrails + evals + database.

**Time:** ~60–90 minutes. **Rule:** explain the concept in plain words, or the day doesn't count.

---

## The loop today

1. **Learn** — the concept above. One focused idea; own it 100%.
2. **Specify** — Take your day-26 brief. Write the full spec *before* AI writes a line. Build to the spec.
3. **Evaluate** — Eval suite passes at your bar. A second human tests it; fix what confuses them.
4. **Business lens** — Write the proposal you'd send the client: scope, timeline, price. The exercise is the skill.
5. **Commit** — push today's work. Your history is your proof.

> AI writes the draft. **You** specify, evaluate, and stand behind it. Never ship output you can't explain or defend.
