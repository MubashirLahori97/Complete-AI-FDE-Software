# 📘 Day 20 — Agents: Goals, Tools & Loops

**Concept:** An agent = a goal + tools + a loop (reason -> act -> observe -> repeat). Powerful and dangerous: loops can spiral.

**Time:** ~60–90 minutes. **Rule:** explain the concept in plain words, or the day doesn't count.

---

## The loop today

1. **Learn** — the concept above. One focused idea; own it 100%.
2. **Specify** — A research agent. Specify the goal, the tools, max steps, and stop conditions.
3. **Evaluate** — Read its full thought/action log. Narrate *why* each step. Find one dumb decision; fix the spec.
4. **Business lens** — Agents are sold as magic and fail as magic. *Constrained* agents with stop rules are the sellable version.
5. **Commit** — push today's work. Your history is your proof.

> AI writes the draft. **You** specify, evaluate, and stand behind it. Never ship output you can't explain or defend.
