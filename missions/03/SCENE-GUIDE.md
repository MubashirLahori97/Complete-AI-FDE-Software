Change the heading size. Notice what stays the same.

First action: **Make the heading bigger**. The scene uses the same saved inputs and local rules as the original experiment. Changes appear immediately. The framed page runs actual HTML, CSS and browser JavaScript.

The illustration is a teaching view, not measured execution or real customer/provider evidence. This is a real local browser page. Changing its heading or style sends no request to an AI service.
