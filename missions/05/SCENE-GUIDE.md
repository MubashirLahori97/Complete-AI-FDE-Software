# Mission 5: learn through the scene

Learn through experiments

## Why this lesson

A shop may offer more services tomorrow. One shared rule can turn each service record into a card without copying the whole page.

## What to look for

Count the service cards before and after the change. More records should produce more cards using the same pattern.

## Start your project

Write three fictional services with an identifier, name and price. Ask AI to display each record using the same card layout.

## Explain your own result

Explain where your service records live, which rule creates the cards, and how each record is identified.
