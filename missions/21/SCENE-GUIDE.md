## Try one change

Run the record assertion with the wrong-record defect present, then remove the defect.

First action: **Inspect the changed records**. The scene uses the same saved inputs and local rules as the original experiment. Changes appear immediately. Use either scene change, inspect a reading moment, or choose Follow the idea. Pause, restart and replay are available.

The illustration is a teaching view, not measured execution or real customer/provider evidence. The updater and assertions execute on two local fictional visits. This is a controlled defect, not a test of your real application.
