# Mission 22: learn through the scene

Release with a way back

## Try one change

Make configuration complete, then compare rollback with and without a data migration.

First action: **Supply the required configuration**. The scene uses the same saved inputs and local rules as the original experiment. Changes appear immediately. Use either scene change, inspect a reading moment, or choose Follow the idea. Pause, restart and replay are available.

The illustration is a teaching view, not measured execution or real customer/provider evidence. This is a release-compatibility model. It does not build, deploy or migrate an external application.

## Your own project: A release you can recover

Release the product to a suitable test or authorized public environment with identified source, configuration and a recovery procedure.

Start here: Ask AI to inspect the current stack, prepare reproducible build/release instructions and name required configuration without secrets.

Use Build this with AI to open the existing project. AI may implement everything. Explain the relevant input, rule and result in your own system; predict a changed case and check what actually happens. Keep your product observations separate from the teaching model.

Inputs and notes use the saved experiment and progress backup. Undo/reset remain available. Playback is temporary and never records mastery. Inspect the numbers and rules for full values. System/3D inspection and guided comparisons remain available.
