# Mission 16: interactive experiment

Permission and budget are different boundaries.

## Start here

Open mission 16 in the academy. Give the model enough budget without granting broader authority.

First action: **Increase the task budget**. Change the controls and observe the result. The browser executes a local teaching model; it does not contact a customer system or an AI provider.

## The idea

A task brief can define the goal, allowed actions, budget and stopping conditions. Sufficient budget does not grant permission. Permission does not remove the need to stop when the budget is exhausted.

## Things you can change

- **Task budget:** starts at 2. Range: 0–10 units, step 1.
- **Operations needed:** starts at 3. Range: 1–6 operations, step 1.
- **Granted authority:** starts at "test". Choices: Read only; Test environment; Explicit live-change authority.
- **Requested action:** starts at "test". Choices: Read information; Change the test environment; Change the live environment.

## A different situation

Ask for a live change while granting only test-environment access. Should more budget make that allowed?

Predict the result before trying it. Record the value you changed, what actually happened and why. Inspect the system parts in 3D or use the equivalent flat diagram. Rotation and separation change your view; the lesson controls change the model.

## What this experiment establishes

This is a local rule executor, not an autonomous AI agent. Each operation costs one fictional unit; no tool or external system is used.
