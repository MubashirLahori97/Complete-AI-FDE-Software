# 📘 Day 17 — Connecting Models to Code

**Concept:** Tool calling = the model decides *what*, your code does *how*. The contract between them (the schema) is the engineering.

**Time:** ~60–90 minutes. **Rule:** explain the concept in plain words, or the day doesn't count.

---

## The loop today

1. **Learn** — the concept above. One focused idea; own it 100%.
2. **Specify** — A natural-language calculator: model calls your calculate(). You define the tool contract.
3. **Evaluate** — Draw the loop: user -> model -> tool -> your code -> model -> answer. Break one link; observe.
4. **Business lens** — Tools connect AI to real business systems (databases, bookings, payments). That's the integration money, supercharged.
5. **Commit** — push today's work. Your history is your proof.

> AI writes the draft. **You** specify, evaluate, and stand behind it. Never ship output you can't explain or defend.
