# 📘 Day 22 — Proof: Evaluating AI Systems

**Concept:** AI output is probabilistic: 'it worked once' proves nothing. Evals = a fixed test set you re-run, your regression safety net.

**Time:** ~60–90 minutes. **Rule:** explain the concept in plain words, or the day doesn't count.

---

## The loop today

1. **Learn** — the concept above. One focused idea; own it 100%.
2. **Specify** — A 20-question eval set with a scoring rubric. AI may *draft* questions; you approve each one.
3. **Evaluate** — Run it. Record 'my bot scores X/40.' Change the prompt, re-run, prove improvement or catch regression.
4. **Business lens** — 'We test every change against 40 cases' is a sentence clients pay for.
5. **Commit** — push today's work. Your history is your proof.

> AI writes the draft. **You** specify, evaluate, and stand behind it. Never ship output you can't explain or defend.
