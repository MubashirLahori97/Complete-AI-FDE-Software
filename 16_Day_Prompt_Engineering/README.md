# 📘 Day 16 — Specification: Prompts as Engineering

**Concept:** A prompt is a *specification* given to a probabilistic machine. Vague specs -> random output. Precise specs -> reliable behavior.

**Time:** ~60–90 minutes. **Rule:** explain the concept in plain words, or the day doesn't count.

---

## The loop today

1. **Learn** — the concept above. One focused idea; own it 100%.
2. **Specify** — A ticket classifier outputting JSON, right 10/10 times. Iterate on the *spec*, not the code.
3. **Evaluate** — 10 test tickets. Score it. Find the failure; fix the specification.
4. **Business lens** — 'Make it behave reliably' is what businesses pay for. Reliability is the product.
5. **Commit** — push today's work. Your history is your proof.

> AI writes the draft. **You** specify, evaluate, and stand behind it. Never ship output you can't explain or defend.
