Download the starter kit in the app's Project tab, then extend it into your own implementation. A starter is not a finished project solution.

## How to use a project

1. Read the main lesson and predict the worked example's result.
2. Open the project guide and write your own scoped requirements.
3. Build the three milestones using fictional or public data.
4. Run the test matrix and record actual outcomes.
5. Complete the app's five acceptance checks and record build evidence.
6. Use the reflection rubric to choose one useful improvement.

The projects in lessons 8, 14, 26, 27, 29, and 30 also produce collaboration, deployment, discovery, or handoff artifacts. Those are part of software engineering and FDE work, even when the final deliverable is documentation rather than a new program.
