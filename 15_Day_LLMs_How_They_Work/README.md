# 📘 Day 15 — How LLMs Actually Work

**Concept:** Next-token prediction at scale. Tokens = the unit of thought *and* money. Context window = working memory. Temperature = randomness dial.

**Time:** ~60–90 minutes. **Rule:** explain the concept in plain words, or the day doesn't count.

---

## The loop today

1. **Learn** — the concept above. One focused idea; own it 100%.
2. **Specify** — Your first API call. Specify model, max tokens, temperature - and predict the cost *before* running.
3. **Evaluate** — Same prompt at temperature 0 vs 1: explain the difference. Price out 10,000 users.
4. **Business lens** — Tokens are money. Every AI business is token economics: cost per user vs. price per user.
5. **Commit** — push today's work. Your history is your proof.

> AI writes the draft. **You** specify, evaluate, and stand behind it. Never ship output you can't explain or defend.
